# Optional Azure artwork

No Microsoft artwork or copied Microsoft license text is bundled here.
Obtain the current official icons and applicable terms from:
https://learn.microsoft.com/en-us/azure/architecture/icons/

The importer preserves user-supplied terms and archive notices alongside the
locally generated pack in `.local/azure-icons/`. Those assets are outside the
root MIT license. See `docs/azure-icons.md` for installation and usage.
